# Writing Skill

## Purpose
Produce clear, well-structured written content including docs, articles, reports, and emails.

## When to Use
Use when composing documentation, technical writeups, summaries, or structured text deliverables.

## Workflow
1. Identify target audience, purpose, and key points.
2. Structure outline logically.
3. Write concise, accurate text following Bob's direct voice.
4. Proofread for clarity, tone, and technical correctness.

## Required Tools
- `file_write` / `documents_write`

## Constraints
- Avoid fluff, hype, and robotic pleasantries.
- Maintain formatting standards (Markdown / plain text).

## Output & Verification
- Clean, well-formatted written document.
